# 天机 · 开奖概率实验室

天机是一款面向历史开奖数据分析、候选预测和真实前向验证的 Android 应用。
应用从开奖接口同步历史与目标期开奖数据，本机统计模型和可选 AI 分析都基于同一份接口历史进行计算。

## 当前版本

- 版本：5.5.9 正式版
- Android：原生 Kotlin + Jetpack Compose
- 构建：Java 17、Gradle 8.13、Android SDK 36
- 正式预测：保留真实 thinking/reasoning，并通过墙钟截止和完整核心立即返回控制等待时间

## v5.5.9 深度思考、后台与对话操作

- 正式预测按省时、自动、深入实际映射模型思考参数；深入模式启用高推理或 DeepSeek max。
- 60/120 期窗口分别使用约 30/40 秒墙钟上限，到期后保留已有推理并沿用同一对话短时补齐最终 JSON。
- 完整 position 与 10 项 scores 到达后立即结束，不再等待长篇解释；DeepSeek V4 使用模型最大输出空间，其他模型交由供应商上限决定。
- 开奖刷新不再取消已经发出的付费 AI 任务，后台运行由进程级控制器和前台服务通知保护。
- 对话断流后抢救已有正文，底层网络错误统一显示为中文。
- 用户与 AI 消息支持长按选择、一键复制纯文本和系统 TTS 朗读。
- 用户消息可“再次提问”，AI 回答可“重新回答”；旧答案保留，新请求明确追加，不会静默重复调用。
- 对话历史迁移至 SQLite 单会话更新，未结算候选按各自目标期从接口历史精确补验。

## v5.5.8 断流恢复与过程收口

- 正式预测流式连接中断后会抢救已接收的完整预测核心；只有部分内容时沿用同一对话补全，不重复执行历史分析。
- Socket、EOF 和普通 I/O 异常统一转换为中文提示，不再在界面显示底层英文错误。
- 推理与结果过程卡片改为分阶段原位更新，避免交替输出时不断向下堆叠。

## v5.5.6 多会话分析对话

- 新增与正式预测完全隔离的分析对话入口。
- 同一条会话可跨越多期开奖持续追问和复盘，例如反馈“上一期没中，降低短期热号权重”。
- 支持新建空白对话、继承策略摘要继续、历史会话恢复和上下文接近上限时自动总结续接。
- 每次候选绑定生成时的目标期；开奖接口更新后，在当前会话中补充实际号码和六码命中状态。
- “AI 配置”和“具体模型”分开选择，并合并接口返回的可用模型。
- 内置综合研判、历史分析、走势研判、遗漏追踪、转移分析和风险审计六种分析人设。
- 兼容 Chat Completions SSE 与 Responses API 流式输出；不支持流式的接口自动降级普通请求。
- 支持基础 Markdown 排版，加粗、列表、引用和分隔线不会再显示原始标记。
- 会话写入应用私有存储；与正式预测数据库、真实成绩、首次冻结结果和多模型共识完全隔离。

## 自动验证

分支持续执行 Debug/Release 单元测试、Android Lint、Debug APK 和 R8 Release APK 构建；只有完整通过的产物用于正式发布。

> 随机开奖不可可靠预测。本项目用于统计实验、记录和真实前向验证，不承诺准确率、收益或必中。
