# 司南记账

司南已重构为本地优先的 Android 自动记账软件。首版使用 Jetpack Compose，并按 Miuix / HyperOS 引用库页面的视觉语言设计：浅紫灰背景、大圆角分组卡片、宽松留白、柔和层级和悬浮底栏。

## 0.1.0-alpha1

- 首页显示本月支出、收入、结余和最近明细。
- 支持手动记账、分类、来源、备注和删除。
- 通过 Android 通知使用权识别支付宝、微信支付、云闪付和 QQ 钱包通知。
- 自动提取金额、收支方向、商户，并按关键词分类。
- 相同通知使用签名去重，避免重复入账。
- 统计页提供本月总支出、日均、笔数和分类占比。
- 支持深色模式与 Android 12+ Monet 动态取色。
- 所有数据使用本机 SQLite 保存，不需要账号，不上传通知或账目。

## 自动记账说明

首次进入后，在“设置 → 通知使用权”中授权司南记账。授权后，新的支付通知会在设备本地解析并写入账本。首版不申请短信权限，也不会读取历史短信。

支付应用的通知文案会随版本和地区变化，无法识别的通知不会写入账本，后续可以继续补充规则与自定义模板。

## 构建

首版源码以校验过的压缩归档保存在 `source/ledger-alpha1.tar.xz.b64`，GitHub Actions 会恢复源码并构建 APK，同时上传可浏览的源码产物。

要求 JDK 17、Gradle 9.5、Android SDK 37。
