# 天机 · 开奖概率实验室

天机是一款面向历史开奖数据分析、候选预测和真实前向验证的 Android 应用。
应用从开奖接口同步历史与目标期开奖数据，本机统计模型和可选 AI 分析都基于同一份接口历史进行计算。

## 当前版本

- 版本：5.5.8 修复版
- Android：原生 Kotlin + Jetpack Compose
- 构建：Java 17、Gradle 8.13、Android SDK 36
- 正式预测：自动/省时模式快速收口，深入模式仍保留完整模型思考

## v5.5.8 断流恢复与过程收口

- 正式预测流式连接中断后会抢救已接收的完整预测核心；只有部分内容时沿用同一对话补全，不重复执行历史分析。
- Socket、EOF 和普通 I/O 异常统一转换为中文提示，不再在界面显示底层英文错误。
- 推理与结果过程卡片改为分阶段原位更新，避免交替输出时不断向下堆叠。

## v5.5.7 速度与后台对话修复

- 正式预测不再给 DeepSeek V4 开放 384K 无边界输出；自动、省时、深入分别使用 8K、4K、32K 的明确预算。
- 正式预测的“自动”和“省时”关闭长思考，直接利用客户端已核验统计生成紧凑评分矩阵；“深入”仍保留完整思考。
- 分析对话关闭、返回或收起后继续在应用级控制器中运行；重新打开可继续查看流式内容和最终结果。
- 只有对话中的“停止”按钮会取消请求，关闭界面不再等同于取消。

## v5.5.6 多会话分析对话

- 新增与正式预测完全隔离的分析对话入口。
- 同一条会话可跨越多期开奖持续追问和复盘，例如反馈“上一期没中，降低短期热号权重”。
- 支持新建空白对话、继承策略摘要继续、历史会话恢复和上下文接近上限时自动总结续接。
- 每次候选绑定生成时的目标期；开奖接口更新后，在当前会话中补充实际号码和六码命中状态。
- “AI 配置”和“具体模型”分开选择，DeepSeek 默认可选 `deepseek-v4-flash` 与 `deepseek-v4-pro`，并合并接口返回的其他模型。
- 内置综合研判、历史分析、走势研判、遗漏追踪、转移分析和风险审计六种分析人设。
- 兼容 Chat Completions SSE 与 Responses API 流式输出；不支持流式的接口自动降级普通请求。
- 支持基础 Markdown 排版，加粗、列表、引用和分隔线不会再显示原始标记。
- 会话写入应用私有目录并使用原子写入；与正式预测数据库、真实成绩、首次冻结结果和多模型共识完全隔离。

## 正式预测与分析对话隔离

v5.5.7 只调整正式预测的推理预算和收口策略，不改变历史同步、首次冻结、目标期核验、评分矩阵校验或真实成绩验证。分析对话继续使用独立客户端与独立存储，关闭对话界面不会取消后台请求。

## 自动验证

分支持续执行 Debug/Release 单元测试、Android Lint、Debug APK 和 R8 Release APK 构建；只有完整通过的产物用于测试。

> 随机开奖不可可靠预测。本项目用于统计实验、记录和真实前向验证，不承诺准确率、收益或必中。
