# 天机 · 开奖概率实验室

天机是一款面向历史开奖数据分析、候选预测和真实前向验证的 Android 应用。
应用从开奖接口同步历史与目标期开奖数据，本机统计模型和可选 AI 分析都基于同一份接口历史进行计算。

## 当前版本

- 版本：5.6.1 时效自适应学习正式版
- Android：原生 Kotlin + Jetpack Compose
- 构建：Java 17、Gradle 8.13、Android SDK 36
- 正式预测：保留真实 thinking/reasoning，并通过墙钟截止和完整核心立即返回控制等待时间


## v5.6.0 持续学习与独立 AI

- AI 对话默认不读取本机候选，真正独立分析；可手动切换参考本机或反向审计。
- 新增可审计在线学习档案，按真实前向结果更新六类因子权重，未中后主动纠偏。
- 正式 AI 与对话 AI 都读取各自配置的长期学习状态，不再每期从零开始。
- 修复 DeepSeek 首轮只思考不出 JSON 时的错误续接，改为同模型关闭思考后结构化收口。
- 档案页可清除显示、只看最近10条或显示全部，不破坏原始记录和完整性链。
