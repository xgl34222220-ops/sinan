# 天机 v6.10 UI 与推送回归矩阵

每次正式发布前至少完成以下组合的截图和人工检查，避免分段控件半框、状态栏重叠、底部 Dock 裁切、键盘重复留白、模型选中态不可读以及推送级别显示错误。

## App 必测尺寸

| 设备宽度 | 字体缩放 | 外观 | 主题 | 必测页面 |
| --- | --- | --- | --- | --- |
| 360dp | 1.00 | 深色 | 跟随彩种 | 预测、策略、档案、设置、通知中心、AI 对话 |
| 360dp | 1.30 | 深色 | Monet | 顶栏、分段按钮、通知筛选、设置详情、AI 对话键盘、底部 AI Dock |
| 412dp | 1.00 | 浅色 | Monet | 全部主页面、弹窗、Bottom Sheet、空态、错误态 |
| 412dp | 1.15 | OLED | 星紫 | 开奖球、档案筛选、通知历史、悬浮 AI Dock |
| 600dp | 1.00 | 深色 | 青玉 | 平板布局、长模型名、双栏候选区域 |

## App 关键交互

- `幸运飞艇 / 澳洲幸运10` 两个按钮始终等宽、完整描边，切换后实时期号与目标期一致。
- 顶栏不与状态栏重叠；返回、通知、刷新触控区域不得小于 48dp。
- 首页动态副标题必须能表达当前彩种、目标期以及 AI 分析状态，长目标期不得挤压右侧操作。
- 中间 AI 为独立主操作而不是第五个 Tab；圆形按钮可以上浮，但 `问 AI / 运行中` 文字不得被底栏或系统手势区裁切。
- AI 运行进度环、按压缩放与触感反馈不得改变底栏整体高度。
- AI 对话键盘开关不得产生重复底部留白。
- 长模型名、目标期和错误说明必须换行或截断。
- 浅色、深色、OLED 文字与边框保持可读。
- 系统字体缩放 1.30 时不允许文字被裁切；至少补一次“字体放大 + 系统显示大小放大”的组合人工检查。
- 通知中心第一屏优先展示消息；类型筛选保持单排，彩种与来源进入高级筛选 Bottom Sheet。
- Bottom Sheet 的重置只改变历史筛选，不允许修改实际接收范围。
- 通知历史按今天、昨天与日期分组，连续未命中展开后显示最近期号轨迹。

## Android 系统通知

- “预测完成”和“风险预警”使用不同系统通知频道。
- 新一期预测主操作显示 `查看预测`；风险事件显示 `查看预警`；恢复命中显示 `查看档案`。
- 普通每期预测默认静默；恢复命中和风险事件允许按通知频道正常提醒。
- 同一彩种、来源和模型从两期升级到三期、四期时更新同一条通知。
- 服务端标题必须原样显示；两期预警不得被重写为三期预警。
- 过期事件可以显示在通知历史，但不得再次弹系统通知。
- 首次启动不主动申请通知权限；打开通知中心后才申请。

## 推送生命周期

| 场景 | 预期 |
| --- | --- |
| App 前台收到 FCM | 合并历史并显示本地通知 |
| App 后台收到 notification + data | 系统显示一次，打开后增量同步历史 |
| App 被划掉 | 点击系统通知冷启动并定位通知中心或预测页 |
| FCM 与 WorkManager 重复到达 | 按 alert ID 去重 |
| Token 更新 | 重新注册，不创建重复设备 |
| 网络断开后恢复 | 使用 after_id 补齐增量事件 |
| 通知权限关闭 | 通知中心继续同步并显示状态说明 |
| 全部已读 | 服务端更新 read-through 游标 |

## Telegram

- 普通 AI 预测使用紧凑排版，只保留彩种、目标期、预测名次、Top 6、模型和连续未中状态。
- 普通 AI 预测默认静默发送，不重复展示来源、训练截止期和固定说明文字。
- 预测消息显示 `查看预测 / 管理面板` Inline Keyboard；风险消息显示 `查看预警 / 管理面板`；恢复命中显示 `查看最新预测 / 打开档案`。
- 连续三期及以上预警、恢复命中仍保持有辨识度的标题与提醒等级。
- Telegram 只推送云端 AI 来源；服务器模型不得误发。
- 超过 8 分钟或目标期已开奖的预测事件必须抑制，不得迟到轰炸。

## 服务端 Web 必测

- 360px 手机、412px Android 浏览器、768px 平板和 1440px 桌面宽度。
- 浅色与深色主题。
- 登录错误、锁定、会话过期和跨站请求拒绝提示。
- 首页服务状态、彩种倒计时、AI 任务阶段、备份状态、消息投递状态和最近异常。
- AI 运行卡必须显示目标期、模型、已用时以及距离开奖前 40 秒硬截止的剩余时间。
- 模型列表读取成功后，大号“读取此 Key 支持的模型”按钮必须缩成 `重新读取模型`，接口与 Key 入口保持次级操作。
- 超长模型名必须截断或换行，不得撑破卡片。
- 模型选中态在不支持 `color-mix()` 的 Android WebView/浏览器中仍必须有清晰主色边框、浅底色和可读文字。
- 消息投递卡集中显示 App/FCM、Telegram 和完整通知链路状态；异常状态不能只依赖颜色表达。
- 档案筛选栏吸顶、分页、空结果和超长模型名。
- 网络缓慢时加载状态不改变页面宽度。
- Worker 硬超时后容器恢复，并保留上次超时状态。

## CI 自动界面契约

- 禁止重新出现“1 路 AI 已完成”等内部状态文案。
- 首页不得重复展示两张目标期摘要卡。
- Refined 关键页面禁止 8sp / 9sp 字号。
- 预测完成通知必须支持直接进入预测首页。
- 底部导航必须保留最小 62dp 可触控高度，悬浮 AI 主按钮不得造成标签裁切。
- README、Android versionName 与正式发行说明必须一致。
