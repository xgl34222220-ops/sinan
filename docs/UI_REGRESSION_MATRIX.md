# 天机 v6.1 UI 与推送回归矩阵

每次正式发布前至少完成以下组合的截图和人工检查，避免分段控件半框、状态栏重叠、键盘重复留白以及推送级别显示错误。

## App 必测尺寸

| 设备宽度 | 字体缩放 | 外观 | 主题 | 必测页面 |
| --- | --- | --- | --- | --- |
| 360dp | 1.00 | 深色 | 跟随彩种 | 预测、策略、档案、设置、预警、AI 对话 |
| 360dp | 1.30 | 深色 | Monet | 顶栏、分段按钮、设置详情、AI 对话键盘 |
| 412dp | 1.00 | 浅色 | Monet | 全部主页面、弹窗、空态、错误态 |
| 412dp | 1.15 | OLED | 星紫 | 开奖球、档案筛选、预警历史、底部导航 |
| 600dp | 1.00 | 深色 | 青玉 | 平板布局、长模型名、双栏候选区域 |

## 关键交互

- `幸运飞艇 / 澳洲幸运10` 两个按钮始终等宽、完整描边。
- 顶栏不与状态栏重叠；返回、通知、刷新触控区域不得小于 48dp。
- AI 对话键盘开关不得产生重复底部留白。
- 长模型名、目标期和错误说明必须换行或截断。
- 浅色、深色、OLED 文字与边框保持可读。
- 系统字体缩放 1.30 时不允许文字被裁切。
- “预测完成”和“风险预警”使用不同系统通知频道。
- 同一彩种、来源和模型从两期升级到三期、四期时更新同一条通知。
- 服务端标题必须原样显示；两期预警不得被重写为三期预警。
- 过期事件可以显示在预警历史，但不得再次弹系统通知。
- 首次启动不主动申请通知权限；打开预警中心后才申请。

## 推送生命周期

| 场景 | 预期 |
| --- | --- |
| App 前台收到 FCM | 合并历史并显示本地通知 |
| App 后台收到 notification + data | 系统显示一次，打开后增量同步历史 |
| App 被划掉 | 点击系统通知冷启动并定位预警中心 |
| FCM 与 WorkManager 重复到达 | 按 alert ID 去重 |
| Token 更新 | 重新注册，不创建重复设备 |
| 网络断开后恢复 | 使用 after_id 补齐增量事件 |
| 通知权限关闭 | 预警中心继续同步并显示状态说明 |
| 全部已读 | 服务端更新 read-through 游标 |

## 服务端 Web 必测

- 360px 手机、768px 平板和 1440px 桌面宽度。
- 浅色与深色主题。
- 登录错误、锁定、会话过期和跨站请求拒绝提示。
- 首页服务状态、彩种倒计时、任务阶段、备份状态和最近异常。
- 档案筛选栏吸顶、分页、空结果和超长模型名。
- 网络缓慢时加载状态不改变页面宽度。
- Worker 硬超时后容器恢复，并保留上次超时状态。


## CI 自动界面契约

- 禁止重新出现“1 路 AI 已完成”等内部状态文案。
- 首页不得重复展示两张目标期摘要卡。
- Refined 关键页面禁止 8sp / 9sp 字号。
- 预测完成通知必须支持直接进入预测首页。
- README、Android versionName 与正式发行说明必须一致。
